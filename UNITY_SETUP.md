# Как открыть и запустить Unity-проект

> Проект — **прототип без готовых ассетов**. Уровень и HUD собираются кодом,
> поэтому сцена создаётся редакторным скриптом при первом открытии.

## Шаги

1. Установи **Unity Hub** и **Unity 6 LTS (6000.x)** с модулем **Android Build Support**.
2. В Unity Hub: **Add → Add project from disk** → выбери папку репозитория (корень).
3. Открой проект (первое открытие сгенерирует `Library/` — это нормально, в git не попадает).
4. Дождись компиляции (прогресс в правом нижнем углу), затем в меню: **DeadRig → Создать сцену** (создаст `Assets/Scenes/Main.unity` с Bootstrap и PrototypeBuilder).
5. Нажми **Play** — прототип соберётся кодом: земля, база, турель, спавн-точки и HUD.
   Волны зомби идут автоматически, турель отстреливается. Кнопки внизу: ферма / турель / исследовать / крафт / волна. Сейв пишется в `Application.persistentDataPath`.

## Что уже есть

- `Assets/Scripts/Core/` — ядро игры (экономика, волны, сейв, престиж, исследования, крафт).
- `Assets/Scripts/Game/` — прототип геймплея (зомби, турель, снаряды, ядро базы, спавн волн).
- `Assets/Scripts/UI/` — программный HUD.
- `Assets/Editor/SetupScene.cs` — создание стартовой сцены (меню **DeadRig → Создать сцену**).

## Важно для агентов

- Сцена и арт пока НЕ закоммичены — после работы в Unity запуши `Assets/Scenes` и новые ассеты.
- Не коммить `Library/`, `Temp/`, `Logs/`, `obj/` (они в `.gitignore`).
