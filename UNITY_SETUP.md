# Как открыть и запустить Unity-проект

> Проект — **скелет** (логика без арта и сцен). Unity на этой машине не запускается,
> поэтому сцена создаётся автоматически редакторным скриптом при первом открытии.

## Шаги

1. Установи **Unity Hub** и **Unity 6 LTS (6000.x)** с модулем **Android Build Support**.
2. В Unity Hub: **Add → Add project from disk** → выбери папку репозитория (корень).
3. Открой проект (первое открытие сгенерирует `Library/` — это нормально, в git не попадает).
4. В меню: **ZombieMiner → Создать сцену** (создаст `Assets/Scenes/Main.unity` с Bootstrap-объектом).
5. Нажми **Play** — в консоли видно, что GameManager запустился, экономика тикает, сейв пишется в `Application.persistentDataPath`.

## Что уже есть

- `Assets/Scripts/Core/` — ядро игры (экономика, волны, сейв, престиж, bootstrap).
- `Assets/Editor/SetupScene.cs` — создание стартовой сцены.
- `Assets/Editor/SetupScene.cs` требует компиляции — если меню не появилось, дождись завершения компиляции (прогресс в правом нижнем углу).

## Что делать дальше (фаза 1)

- UI (HUD: хеши, кристаллы, кнопки апгрейдов, волна).
- Враги/турели (спрайты, движение, стрельба).
- Интеграция rewarded-рекламы.
- См. `docs/game-design.md` и `STATUS.md`.

## Важно для агентов

- Сцена и арт НЕ закоммичены ещё — после работы в Unity запуши `Assets/Scenes` и новые ассеты.
- Не коммить `Library/`, `Temp/`, `Logs/`, `obj/` (они в `.gitignore`).
