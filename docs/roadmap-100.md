# DeadRig — программа 100 улучшений

> Утверждено владельцем: выполнить пункты 1–100 батчами. Активная платформа — нативный Android, без Unity.

## Правила исполнения

- 10 батчей по 10 улучшений; внутри батча независимые задачи ведутся параллельными потоками.
- Статусы: ⬜ очередь, 🔨 в работе, ✅ готово, 🧪 нужен тест устройства.
- Каждый подбатч: Gradle debug → commit → push. Каждый релизный батч: release/lint/apksigner → APK → STATUS.md → push.
- Зависимые системы выполняются после фундамента: инвентарь → качество/редкость → модификаторы → комплекты.
