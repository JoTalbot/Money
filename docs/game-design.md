# Game Design Document — DeadRig

## 1. Концепция (жанр)

**Гибрид:** idle-тайкун + база-выживание + волны зомби + **исследования и крафт (как в X-COM/UFO)**, в сеттинге крипто-майнинга.

**Название:** DeadRig. **Арт-стиль:** красивая объёмная 2.5D-изометрия 2:1: тёмный индустриальный бункер, многослойные объекты, бирюзовый энерго-свет, оранжевые сигнальные акценты. Рендер нативный Android Canvas, без Unity.

Игрок — оператор подземного бункера-криптофермы в постапокалипсисе. Ферма **майнит** внутриигровую валюту («хеши»), а периодически приходят **волны зомби**, которые надо отбивать (с зомби падает **«лом»** — ресурс для крафта). Доход тратится на три фронта: *майнинг* (больше дохода), *оборону* (чтобы выжить) и *науку* (исследования + крафт открывают новое оружие и бонусы).

> ⚠️ «Хеши» — **игровая** валюта, НЕ реальная криптовалюта. Реальный токен-слой — фаза 3 (см. «Токен-ready»).

## 2. Core loop (минута игрока)

1. Пассивный майнинг капает «хеши» (idle).
2. Волна зомби → выжил → награда (хеши + лом).
3. Тратишь ресурсы: апгрейд фермы / турелей, запуск **исследования**, запуск **крафта** предмета.
4. Исследование завершилось → открылся новый рецепт/бонус → крафтишь лучшее оружие.
5. Усилился → новая волна сложнее → …
6. Престиж («переезд на новый узел сети») → сброс прогресса ради постоянного множителя дохода.

## 3. Системы и механики

### 3.1 Экономика (см. `EconomyManager`)
- **Мягкая валюта — «хеши»**: добывается майнингом и волнами, тратится на всё.
- **Жёсткая валюта — «кристаллы»**: премиум, редко, за IAP/награды/события.
- **Ресурс — «лом»**: падает с зомби (награда за волну), нужен для крафта и исследований.
- Скорость майнинга = базовая × уровень фермы × множитель престижа × бонусы исследований.
- **Оффлайн-доход**: 50% от онлайн-скорости, максимум 8 часов.
- Стоимости растут экспоненциально (×1.5–1.6 за уровень).

### 3.2 Волны зомби (см. `WaveManager`)
- Число врагов = 5 + 3×номер волны; HP врага = 10 × 1.25^(волна−1).
- Награда: 20×номер «хешей» + 10×номер «лома» (лом × бонус исследований).

### 3.3 Tower defense: маршруты и башни
- Зомби выходят из четырёх разломов и идут к ядру по извилистым, визуально обозначенным дорогам.
- Вдоль дорог расположены 8 фиксированных монтажных площадок.
- Скрафченная башня попадает в резерв; игрок касается свободной площадки для установки.
- Типы: пулемётная (быстрая), лазерная (×2 урон и +дальность), тесла-башня (×2.8 урон, тяжёлый импульс).
- Исследования обороны: урон, сервоприводы скорострельности, квантовый радар дальности, тесла-технология, модульные улучшения.
- Крафт: три типа башен, комплект усиления уровня всех башен и стены базы.
- Нажатие на установленную башню открывает локальное улучшение, перемещение и демонтаж.
- Враги: обычный, быстрый, бронированный, токсичный; каждая 10-я волна содержит босса.
- Сопротивления создают контрпики: броня держит пули, лазер эффективен против бегунов, тесла особенно полезна против босса.
- Ручной бой: tap по зомби — ×1.65 одиночный выстрел, удержание — огонь по кулдауну.
- Боевая глубина: криты, зоны головы, боезапас/перезарядка, перегрев, комбо и точный прицел после удержания.
- Три постоянных оружейных модуля: ствол, охлаждение и магазин.
- Каждое оружие имеет спецспособность; убийства заряжают орбитальный ультимейт.
- Отдельная оружейная ветка: пистолет → автомат → дробовик → рельсотрон и шесть специализированных моделей.
- Снайперка усиливает headshot; гранатомёт взрывает группу; огнемёт поджигает; крио замедляет; тесла цепляется; кислота снимает защиту.
- Боевой дрон автоматически атакует, а специальные патроны дают бронебойный, огненный или электрический эффект.
- При крафте определяется редкость и случайные параметры урона, темпа и критического шанса.
- Тесла поражает основную и до двух соседних целей; крио-башня замедляет цель на 52%.
- Ежедневный контракт: 50 убийств, 5 волн, 100 ручных выстрелов; награда — кристаллы и лом.

### 3.4 Престиж (см. `MetaProgression`)
- Сброс валюты, лома и уровней → +50% к доходу навсегда.
- Исследования, рецепты, инвентарь и кристаллы **не сбрасываются** (мета-прогресс).
- Порог: 1000 × 10^престиж.

### 3.5 Исследования (см. `ResearchManager`, `ResearchCatalog`) — как в X-COM/UFO
- Дерево технологий: узел = проект (название, стоимость в хешах+ломе, время, требования).
- У проектов есть **время выполнения в реальном времени** (в т.ч. оффлайн).
- **Слоты**: число лабораторий = число параллельных исследований (старт: 1, открывается +1).
- Эффекты: +% майнинга, +% лома, +% урона, открытие рецептов крафта, +слот лаборатории.
- Стартовое дерево: Оптимизация ASIC → Разбор зомби-техники → Лазерная турель → Бронебойные патроны → Вторая лаборатория.

### 3.6 Крафт / производство (см. `CraftingManager`, `CraftingCatalog`) — как мануфактура в UFO
- Рецепты: вход (хеши + лом) → время производства → предмет в инвентарь.
- Рецепты открываются исследованиями (часть доступна сразу).
- **Цеха**: число параллельных производств (старт: 1).
- Предметы: турели (базовая, лазерная), стены, бустеры (расходники).

### 3.7 Мета (после MVP)
- Дерево технологий глубже, коллекция героев/турелей, ежедневные квесты, сезонный пасс, скины.

## 4. Монетизация (гибрид, как выбрано)

**Rewarded-реклама:**
- ×2 оффлайн-дохода, ускорение майнинга/исследования на N минут, мгновенное завершение крафта, бесплатный сундук, «оживиться» после поражения.

**IAP:**
- Отключение рекламы (no-ads), пакеты «хешей»/«кристаллов»/«лома», бустеры, +слоты лабораторий/цехов, скины героев/базы, сезонный пасс.

## 5. Токен-ready слой (Путь C)

- Вся валюта/ресурсы проходят через **одну точку** — `EconomyManager` (методы `AddSoft/AddHard/AddScrap/TrySpend*`).
- Фаза 3: под эти методы подкладывается `WalletAdapter` → реальный смарт-контракт/токен (отдельный web/APK-дистрибутив, вне Google Play).
- Жёсткая валюта («кристаллы») — кандидат на будущий токен.

## 6. KPI-цели

- D1 retention > 40%, D7 > 15%, сессия 8–12 минут, ARPDAU > $0.05 (цель роста).
