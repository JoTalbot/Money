## 2026-08-14 — Сборка APK в окружении агента

- Собран **нативный Android-порт** DeadRig (`android-demo/`, чистый Java, без движка) — потому что Unity-сборка требует Unity Editor + лицензию, которых нет в песочнице.
- Стек сборки: JDK 11 + Gradle 7.6.1 + AGP 7.4.2 + compileSdk 33. APK: debug и release (подписаны).
- Порт повторяет Unity-ядро 1:1 (экономика, волны, турели, исследования, крафт, сейв, оффлайн-доход).
- Готовые APK лежат в `android-demo/releases/`.

## 2026-08-14 — Прототип геймплея (фаза 1)

- Написан прототип: зомби (`Enemy`), турели (`Turret`), снаряды (`Projectile`), ядро базы (`BaseCore`), спавн волн (`WaveController`), программный HUD (`HUD`).

- HUD: валюты, волна, HP базы, кнопки «Ферма / Турель / Исследовать / Крафт / Волна», экран поражения с рестартом.

## 2026-08-14 — Название и арт-стиль (утверждено владельцем)

- **Название игры:** **DeadRig**. Обыгрывает майнинг-ферму («rig») и зомби-тему («dead»). Короткое и брендовое.
- **Арт-стиль:** **low-poly 3D**. Причина: глубже и атмосфернее, выделяется среди 2D-казуалок.
- Namespace кода переименован `ZombieMiner` → `DeadRig`.

## 2026-08-14 — Исследования и крафт (как в X-COM/UFO)

- **Добавлены исследования** (дерево технологий с временем выполнения и слотами-лабораториями) и **крафт/производство** (мануфактура из ресурсов) — по запросу владельца «как в UFO 2».
- Введён ресурс **«лом»** (падает с зомби) — материал для крафта и исследований.
- Исследования и крафт идут **в реальном времени оффлайн** (фиксированный `finishUtc`) — для ретеншена («вернусь — а лазерная турель уже готова»).
- Исследования/рецепты/инвентарь **не сбрасываются** при престиже (мета-прогресс).
- Сейв поднят до версии 2, добавлен `Sanitize()` для миграции старых сейвов.

## 2026-08-14 — Нативная 2D-изометрия без Unity

**Решение владельца:** активную версию DeadRig делать без Unity; использовать качественную 2D-изометрию.

**Реализация:** продукт живёт в `android-demo/`. `GameView` выполняет изометрическую проекцию 2:1 и векторно рисует тайлы, бункер, турели, зомби, порталы, свет и VFX через Android Canvas. HUD создаётся нативными Android View. Unity-код заморожен как legacy.

**Причины:** уже существующий нативный порт быстрее превращается в устанавливаемый APK, не требует Unity на машине и сохраняет полный контроль над лёгким мобильным рендером.

## 2026-08-14 — Tower defense на фиксированных площадках

**Решение владельца:** добавить режим защиты башнями вдоль маршрута зомби; башни должны развиваться через исследования и крафт. Технология остаётся нативной Android, без Unity. Визуал — объёмная 2.5D-изометрия.

**UX-решение:** четыре извилистых маршрута и восемь фиксированных площадок. Готовая башня попадает в резерв, затем игрок касается площадки. Это хорошо читается на портретном телефоне и исключает ошибочную установку на дорогу.

**Прогрессия:** пулемётная, лазерная и тесла-башня; исследования урона, скорострельности и дальности; крафт новых башен, стен и комплектов общего усиления.
