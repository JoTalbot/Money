# STATUS.md — Состояние проекта

> Последнее обновление: 2026-08-14 (агент)

## Где мы сейчас

- Концепция: «зомби-база + idle-тайкун» в сеттинге крипто-майнинга, исследования и крафт как в X-COM/UFO.
- Название: **DeadRig**.
- Новое прямое решение владельца: **качественная 2D-изометрия, без Unity**.
- Активный продукт: нативный Android-проект `android-demo/` (Java + Android Canvas).
- Unity-прототип в `Assets/` заморожен как legacy: не изменять и не развивать без нового указания владельца.

## Что сделано

- [x] Ядро нативного Android-демо: экономика, волны, турели, исследования, крафт, сейв и оффлайн-доход.
- [x] Полностью заменён примитивный вид сверху на собственный 2D-изометрический рендер 2:1.
- [x] Изометрическая тайловая арена с глубиной граней и корректным порядком отрисовки.
- [x] Векторно отрисованные бункер, турели, зомби, порталы спавна и энерго-снаряды.
- [x] Освещение, свечение, тени, виньетка, защитный периметр и индикатор HP базы.
- [x] Переделан мобильный HUD: компактные ресурсы/статусы, единая sci-fi палитра, новые кнопки и экран поражения.
- [x] Спавн зомби привязан к четырём видимым изометрическим разломам.
- [x] Версия поднята до **0.2.0** (`versionCode 2`).
- [x] Gradle-сборка и release lint успешно пройдены.
- [x] Подпись APK проверена `apksigner` (v1 + v2).
- [x] Готовые APK:
  - `android-demo/releases/DeadRig-v0.2.0-isometric-release.apk`
  - `android-demo/releases/DeadRig-v0.2.0-isometric-debug.apk`

## Риски

- Java Canvas с множеством свечений использует software layer; FPS нужно проверить на слабых устройствах.
- Параллельная работа агентов → конфликты; перед работой обязателен `git pull --rebase`.
- Секреты и ключи не коммитить. Release-keystore хранится вне репозитория.
