# STATUS.md — Состояние проекта

> Последнее обновление: 2026-08-14 (агент)

## Где мы сейчас

- Концепция: **idle + zombie tower defense + исследования/крафт** в сеттинге крипто-майнинга.
- Название: **DeadRig**.
- Активный продукт: нативный Android `android-demo/` (Java + Canvas), **без Unity**.
- Визуал: красивая объёмная 2.5D-изометрия 2:1.
- Unity-прототип в `Assets/` заморожен как legacy.

## Что сделано

- [x] Экономика, волны, сейв, оффлайн-доход, исследования и крафт.
- [x] Объёмная изометрическая тайловая арена: грани, тени, свет, свечение, виньетка и VFX.
- [x] Векторные бункер, турели, зомби, порталы и энерго-снаряды.
- [x] **Tower defense:** четыре извилистых маршрута от порталов к ядру.
- [x] Дороги визуально выделены объёмным полотном и сигнальной разметкой.
- [x] Восемь фиксированных монтажных площадок вдоль маршрутов.
- [x] Скрафченная башня попадает в резерв; установка — касанием свободной площадки.
- [x] Миграция старых сейвов: ранее созданные башни автоматически раскладываются по слотам.
- [x] Типы башен: пулемётная, лазерная, тяжёлая тесла-башня с разным уроном/дальностью/темпом.
- [x] Исследования обороны: урон, скорострельность, дальность, тесла-технология, модульная оборона.
- [x] Крафт: три башни, комплект усиления общего уровня, стены.
- [x] HUD показывает установленные башни и резерв.
- [x] Версия **0.3.0** (`versionCode 3`).
- [x] Debug и release собраны; release lint пройден, подпись APK v1/v2 проверена.
- [x] Готовые APK:
  - `android-demo/releases/DeadRig-v0.3.0-tower-defense-release.apk`
  - `android-demo/releases/DeadRig-v0.3.0-tower-defense-debug.apk`

## Риски

- Software Canvas со свечениями требует проверки FPS на слабых телефонах.
- Автовыбор рецепта удобен для прототипа, но перед релизом нужен полноценный экран цеха.
- Секреты и release-keystore не коммитить.
