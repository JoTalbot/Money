# Money — DeadRig (сверххитовая Android-игра)

Проект нативной Android-игры: idle + zombie tower defense в красивой объёмной 2.5D-изометрии. Активная версия находится в `android-demo/`; Unity-ветка заморожена и не используется.

## Для агентов

Перед началом работы обязательно прочитайте:
1. `AGENTS.md` — правила работы (мультиагентность, параллельная работа, контекст).
2. `STATUS.md` — текущее состояние и "где мы остановились".

## Состояние

См. `STATUS.md`. Проект на этапе выбора концепции игры.
